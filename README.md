# CT Demand Marketing Dashboard

A single-page dashboard tracking Chotot's **marketplace demand** — DAU, DAU-with-Lead, and Total Lead
for the whole platform, broken down by user type, channel, and vertical, with actuals vs. forecast
(FC0/FC1/FC2). One static HTML file, no backend; data is baked into the page and refreshed from BigQuery.

- **Live:** https://kiethuynhphu-ct.github.io/ct-demand-marketing/ (GitHub Pages, served from the `exec-summary-mtm-source` branch)
- **Repo:** https://github.com/kiethuynhphu-ct/ct-demand-marketing (public)
- **Upstream / original:** https://github.com/chile-ct/ct-demand-marketing (the manager's production copy — history and full dashboard)

> This README describes the **`exec-summary-mtm-source`** branch, which is what the Live link serves.
> On this branch the dashboard is scoped to two tabs: **Executive Summary** and **Breakdown by Vertical**.

## Data sources

The dashboard is **static** — every number is a JavaScript constant in `src/index.html`. The tables and
sheets below are the **source of record** for those constants (populated from BigQuery / the marketing
plan sheet). See the [freshness caveats](#caveats-read-before-quoting-a-number) — several of these will
hand you a confident but wrong number if you skip them.

All BigQuery tables live in project **`chotot-dwh`**.

### Caveats — read before quoting a number

- **O-014 — VEH and Apr/May are both disputed.** `mtm_chotot_vertical_dau_mau` reports platform-total Total Lead **~17–18% higher than the legacy source for April and May 2026 specifically** (Apr 5,626,950 vs 4,758,835; May 5,643,038 vs 4,814,123) — every other month agrees within ~0.5%. At **per-vertical** grain the same source puts VEH Total Lead **+93% in Apr** (1,481,312 vs the old 766,108) and **+71% in May** (1,228,473 vs 719,097) — every other vertical/month agrees within ~2%. The four verticals' new-source sum is internally consistent with the platform-total Chotot figure, so the old VEH number looks like the outlier, but this is **not confirmed** by the table owner (`thanh_nguyenchi`). Never quote VEH or platform Apr/May Lead without stating the dispute.
- **Channel overcount is by design.** Channel data double-counts a user active in 2+ channels in a period (~1.3–1.5% DwL overcount observed). In the production dashboard each breakdown carries an **"Unattributed" row** = authoritative total − sum of channel rows, which can legitimately go **negative**. Channel rows will *not* sum to the total — don't "fix" it. (This branch's channel card does not yet add the Unattributed row.)
- **`daumaulead_mkt_rp` is stale** (see table above). Prefer `mtm_chotot_vertical_channel` for anything recent.
- **Vertical figures don't reconcile to the platform total.** Platform DAU runs a consistent ~18–20%/day higher than PTY+JOB+VEH+GDS summed (users who browse the platform without entering a specific vertical). Unexplained (O-015) — flag it, don't paper over it.
- **MAU / MAU w/ Lead / DAU-MAU are hardcoded** on the platform-total (Exec Summary) row only — out of scope this round. Per-vertical MAU/MAU w/ Lead **are** live (see Breakdown by Vertical above).
- **Forecast vintages cover different windows** (FC0 all year · FC1 Apr–Dec · FC2 Jul–Dec). Comparing an actual to the wrong vintage produces a meaningless variance.

## How to make a change

Edit **only** `src/index.html` — `dist/index.html` and root `index.html` are generated and will be overwritten.

```bash
# 1. Edit the source
$EDITOR src/index.html

# 2. Build (writes BOTH dist/index.html and index.html)
node build.js

# 3. Preview locally
python3 -m http.server 8000        # then open http://localhost:8000/dist/

# 4. Push
git add src/index.html dist/index.html index.html
git commit -m "feat: ..."
git push
```

You can also just push `src/index.html` on its own — the **Build on Source Change** GitHub Action
(`build-on-source-change.yml`) recompiles and commits `dist/index.html` + `index.html` for you.
GitHub Pages redeploys automatically in ~1–2 minutes. (The service worker forces a fresh fetch; if you
still see an old version, close the tab fully and reopen.)
